# Hi, I'm Sinan.

I'm a **DevOps engineer in Warsaw**. I run the DevOps function at **Ulula**, an EcoVadis company, across a multi-cloud estate: **AWS EU, AWS China and GCP in Saudi Arabia**, managed end to end in **Terraform**.

I'm work-authorized in Poland, so **no visa sponsorship is needed**.

## What I work on

- **Infrastructure as code:** Terraform module libraries that work across both AWS partitions (commercial and China), and importing live estates into Terraform without breaking them.
- **CI/CD:** Azure DevOps pipelines with zero-downtime deploys, using OIDC federation instead of static keys.
- **Cloud security:** SSO everywhere (EntraID + IAM Identity Center), SSM instead of SSH, AWS Network Firewall, GuardDuty and Security Hub, and SIEM integration.
- **Cost and reliability:** FinOps, backups and disaster recovery, and monitoring that pages for the right things.
- **Kubernetes:** EKS, AKS and Rancher, from earlier roles building clusters from scratch.

## Before this

- **PowerDev** (renewables, 2021–2023): sole infrastructure engineer. Built EKS and AKS with Terraform, scaled an optimization solver to 300 cores, and migrated a 10 TB Aurora PostgreSQL database.
- **Gözen Holding** (aviation, 2018–2020): on-prem to cloud-native. Migrated VMware to OpenNebula, moved Linux VMs to Kubernetes, and ran a Zabbix fleet of 300+ servers.
